Enroll a FIDO USB key

Step 1: Enroll the key

Insert the FIDO key, then press Enroll Key. The browser asks for the key's PIN, or has you set one if the key has none, then asks for a touch. The number is stored on the key as digits only; it is the User ID on the main page.

Step 2: Scan with your phone

The main page opens with the phone number as the User ID. Press Continue there, enter the key's PIN and touch the key when the phone asks, verify the number, then enroll the passkey.
